WebAssembly (WASM) と Web Workers の登場により、かつてバックエンドサーバーが担っていた重い演算処理を、ユーザー端末のハードウェア上で安全かつ高速に実行できるようになりました。

これによりサーバー維持費がゼロに近づき、ユーザーのプライバシーを守りながら圧倒的な処理速度を提供できます。
