몇 년 전, 원래대로라면 10초 만에 끝났어야 할 간단한 작업을 하려던 적이 있었습니다. 이미지 하나를 압축하고 대학 서류 세 장을 하나의 PDF로 합치는 일이었죠. 포털 검색 결과 맨 위에 뜬 사이트를 클릭하자마자 이메일 주소를 입력하라는 팝업창이 떴고, 이어서 7일 무료 체험을 시작하려면 신용카드 정보를 입력하라는 안내 화면이 나타났습니다.

어렵게 찾아낸 무료 변환 사이트에서는 제 개인 인적 사항이 담긴 문서가 이름도 모르는 외국의 원격 클라우드 서버로 천천히 업로드되는 진행 표시줄을 멍하니 지켜봐야 했습니다.

그 경험은 큰 충격과 회의감을 안겨주었습니다. 왜 고작 PDF 페이지를 회전하거나 사진 크기를 조절하는 단순한 작업 때문에 소중한 개인 파일을 지구 반대편으로 전송해야 할까요? 오늘날의 노트북과 스마트폰은 고성능 멀티코어 CPU와 넉넉한 RAM을 갖추고 있습니다. 웹 브라우저는 더 이상 단순한 문서 뷰어가 아니라 강력한 소프트웨어 실행 환경입니다.

저는 이러한 불합리한 방식을 바꾸고자 인도 푸네에서 **LadeStack** (https://ladestack.in/) 을 시작했습니다. 목표는 분명했습니다. 복잡한 가입 절차 없이, 모든 연산을 사용자 기기 안에서 완결하며, 프라이버시를 철저히 보장하는 실용적인 개발자 도구와 웹 애플리케이션을 만드는 것입니다.

## 오늘날 웹 유틸리티들이 안고 있는 문제점

현재 인터넷에 존재하는 수많은 도구 사이트들은 사용자의 편의보다는 광고 수익과 연락처 수집에 초점을 맞춰 설계되어 있습니다.

1. **강제적인 회원가입 장벽**: 일 년에 한두 번 쓸 도구를 위해 계정을 만들고, 인증 메일을 열어보고, 새로운 비밀번호를 외워야 합니다.
2. **원격 서버로의 파일 유출 위험**: 이력서, 계약서, 영수증, 가족 사진을 업로드하는 순간, 해당 데이터가 어디에 저장되고 누구에게 노출되는지 통제할 수 없게 됩니다.
3. **인위적인 기능 제한**: PDF 병합이나 코드 서식 정리 같은 기초적인 작업에 고의로 지연을 걸거나 횟수를 제한해 월간 구독을 유도합니다.
4. **번거로운 로컬 환경 설정**: 새로운 아이디어를 빠르게 테스트해보고 싶어도 Node.js 설치부터 패키지 빌드, 환경 변수 설정까지 지나치게 많은 시간이 소모됩니다.

소프트웨어는 사람의 발목을 잡아서는 안 됩니다. 작업을 시작하려고 할 때 도구는 즉시 열리고 군더더기 없이 작동해야 합니다.

## LadeStack을 이끄는 네 가지 핵심 원칙

브라우저 기반 IDE인 **GB Coder**부터 문서 유틸리티인 **LS PDF**, **MD2PDF**에 이르기까지, LadeStack의 모든 제품은 네 가지 명확한 원칙 아래 개발됩니다.

### 1. 단순한 약속이 아닌 아키텍처로서의 로컬 실행

사용자의 프로세서와 최신 브라우저 API로 처리할 수 있는 작업이라면 절대 서버로 파일을 전송하지 않습니다. **LS PDF**와 **LS Image Compressor**의 병합, 분할, 압축, 워터마크 처리는 WebAssembly, Web Workers, HTML5 Canvas API를 통해 전적으로 브라우저 탭 내부에서 실행됩니다. 파일을 서버로 전송받지 않으므로 데이터가 외부로 유출될 위험 자체가 없습니다.

### 2. 가입과 진입 장벽 없는 즉각성

코드를 정리하거나, **Swift Resume**으로 채용 관리 시스템(ATS) 친화적인 이력서를 작성하거나, **Bharat Land Converter**로 토지 면적을 환산할 때 로그인은 전혀 필요하지 않습니다. 페이지가 로드되는 즉시 작업을 시작할 수 있고, 완료 후 결과물을 로컬 디스크로 내려받으면 서버에는 아무것도 남지 않습니다.

### 3. 로컬 우선 영속성

무리하게 클라우드 동기화를 강제하지 않고, 브라우저 내장 스토리지인 `IndexedDB`와 `localStorage`를 우선 활용합니다. GB Coder에서 작업한 소스 코드나 이력서 초안은 브라우저를 닫았다가 다시 열어도 그대로 유지됩니다. 필요할 때 언제든 ZIP 압축 파일이나 PDF로 추출할 수 있습니다.

### 4. 시각적 공해요소를 걷어낸 실용적인 UI

작업 도구는 안정감과 명확함을 제공해야 합니다. 눈을 어지럽히는 광고 배너나 유도성 팝업을 배제하고, 깔끔한 타이포그래피, 키보드 접근성, 직관적인 계층 구조에 집중합니다.

## 지금까지 구축한 주요 제품군

개인적인 스크립트와 아키텍처 실험에서 출발한 LadeStack은 현재 실용적인 도구 생태계로 자리 잡았습니다.

- **GB Coder** (`code.ladestack.in`): Monaco Editor를 바탕으로 정적 웹 개발부터 WebContainers 기반의 실제 Node.js 환경까지 브라우저 내에서 직접 구동하는 온라인 IDE.
- **LS PDF** (`pdf.ladestack.in`): 서버 업로드 없이 브라우저 메모리 안에서 17가지 PDF 작업(병합, 분할, 압축, 텍스트 추출 등)을 수행하는 로컬 전용 PDF 도구.
- **MD2PDF** (`md2pdf.ladestack.in`): 마크다운 문서와 GitHub 저장소 내용을 KaTeX 수학 수식 및 구문 강조가 적용된 완성도 높은 PDF 문서 및 도서로 변환하는 퍼블리싱 도구.
- **LS Image Compressor** (`img.ladestack.in`): Canvas API를 활용해 기기 내부에서 JPEG, PNG, WebP 이미지 압축 및 포맷 변환을 처리하는 이미지 최적화 도구.
- **Swift Resume** (`resume.ladestack.in`): 실시간 A4 미리보기와 로컬 저장을 지원하는 구직자 맞춤형 이력서 빌더.
- **Bharat Land Converter** (`land.ladestack.in`): 인도의 지역별 전통 토지 면적 단위(Guntha, Bigha, Biswa 등)와 국제 표준 단위를 상호 환산하는 전문 공학 도구.

## 기술적인 현실과 도전 과제

브라우저 내에서 복잡한 연산을 수행하는 데에는 현실적인 기술적 장벽이 따릅니다. 브라우저 탭은 엄격한 메모리 제한을 가지며, 대용량 PDF나 고해상도 이미지를 비효율적으로 다루면 저사양 기기에서 브라우저가 멈출 수 있습니다.

이를 해결하기 위해 UI 렌더링을 방해하지 않는 **Web Workers** 분산 처리, 메모리 누수를 방지하는 `Uint8Array` 기반 바이너리 조작, 점진적 청크 스트리밍 방식을 깊이 있게 적용하고 있습니다.

혼자서 LadeStack을 만들어가며 배운 가장 큰 교훈은, 세상에서 가장 가치 있는 도구는 요란하게 자신을 뽐내지 않고 즉각적으로 실행되며, 사용자의 데이터를 온전히 존중하는 조용한 소프트웨어라는 점입니다. 저는 앞으로도 그 원칙을 지켜나갈 것입니다.
