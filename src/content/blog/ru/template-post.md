Добро пожаловать в **шаблонную статью блога**. Этот материал полностью написан в стандартном формате Markdown (`.md`) и автоматически преобразуется в чистый семантический HTML с помощью Astro JS во время сборки.

Каждая публикация в этом портфолио следует строгому правилу девяти языков: одна и та же статья представлена девятью отдельными файлами Markdown — по одному для каждого поддерживаемого языка (`en`, `jp`, `ko`, `zh`, `ru`, `pt`, `tr`, `fr` и `es`).

## 1. Почему чистый Astro JS и Markdown идеальны для SEO

Поисковые системы отдают приоритет быстрым HTML-документам с четкой семантической структурой и точными языковыми метаданными. Написание статей в Markdown и рендеринг через Astro дают ключевые преимущества:

- **Нулевая нагрузка на клиент**: Файлы Markdown компилируются напрямую в легкие HTML-теги (`<article>`, `<h2>`, `<p>`, `<pre>`, `<blockquote>`) без лишнего JavaScript-кода.
- **Локализованные URL-адреса**: Каждый язык имеет собственный префикс пути в URL, например `/ru/blog/template-post`, `/en/blog/template-post` и `/jp/blog/template-post`.
- **Автоматическая разметка `hreflang`**: Каждая страница содержит ссылки на восемь переведенных версий в секции `<head>`, что помогает поисковикам показывать нужный язык каждому пользователю.

## 2. Структура папок многоязычного блога

Чтобы добавить новую статью в будущем, достаточно создать файл Markdown с одинаковым именем (slug) в каждой из девяти языковых папок:

```text
src/content/blog/
├── en/template-post.md
├── jp/template-post.md
├── ko/template-post.md
├── zh/template-post.md
├── ru/template-post.md
├── pt/template-post.md
├── tr/template-post.md
├── fr/template-post.md
└── es/template-post.md
```

### Стандартная схема Frontmatter

Каждый файл Markdown начинается с блока YAML frontmatter, который задает локализованные метаданные статьи:

```yaml
---
title: "Заголовок статьи на выбранном языке"
description: "Краткое SEO-описание для поисковых систем и социальных сетей."
pubDate: "2026-11-01"
readingTime: 4
category: "Engineering"
slug: "your-post-slug"
lang: "ru"
---
```

## 3. Мгновенное переключение языков

Когда читатель меняет язык в панели навигации во время чтения этой статьи, сайт сохраняет текущую страницу и сразу открывает соответствующий переведенный файл Markdown.

> Хорошая архитектура не мешает процессу письма. Пишите тексты в чистом Markdown, переводите их на девять языков, а компиляцию в HTML и SEO-оптимизацию возьмет на себя Astro.
